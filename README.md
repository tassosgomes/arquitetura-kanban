# arquitetura-kanban

Aplicação Next.js (App Router) do MVP de Gestão de Atividades de Arquitetura, com PostgreSQL no Docker Compose e autenticação OIDC contra o Logto Cloud — sem Identity Provider no Compose. Para pré-requisitos, variáveis, Compose e diagnóstico, use o [guia de desenvolvimento local](docs/guides/local-development.md).
